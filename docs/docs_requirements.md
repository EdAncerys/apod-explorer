# Pinnacle Pet Group Web Technical Test

## NASA APOD Explorer - Technical Test

Build a React application that interacts with NASA’s Astronomy Picture of the Day (APOD) API ([https://api.nasa.gov/](https://api.nasa.gov/)).

---

## 🔑 API Key

Use `DEMO_KEY` for testing purposes.

---

## ⚙️ Setup

- Use **Create React App** or **Vite**.
- **Do not** use UI frameworks (e.g., Material UI, Bootstrap).
- Use **plain CSS** or **styled-components** for styling.

---

## ✨ Features

1. Display **today’s APOD**:

   - Image or video
   - Title
   - Date
   - Explanation

2. Add a **date picker** to fetch APOD for a specific date  
   _(Range: June 16, 1995, to today)_

3. Let users **mark APODs as favourites** and show a **favourites list**:

   - Display title and date of favourites

4. **Bonus:** Add a “Remove” button to delete items from the favourites list

---

## ✅ Requirements

- Handle **loading** and **error** states
- Use **React hooks** (`useState`, `useEffect`) for state and API interactions
- Break the app into **reusable components**
- Style the app **responsively** using **CSS**
